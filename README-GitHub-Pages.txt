GitHub Pages 修正版：馬可 × 艾斯

1. 將本 ZIP 的 public 資料夾內容複製到你的 GitHub 專案 public 資料夾，取代同名檔案。不要把 public 再放進 public。
2. 保留原本 .git 和 .github（部署設定）。在 Fork Stage、Commit、Push。等部署成功後按 Ctrl+F5。
3. 開啟網站 #login，使用你指定的新帳密。每次重新整理需重新登入。
4. 編輯、儲存草稿只影響目前瀏覽器。按「匯出更新檔」下載 content.json。
5. 把下載的 content.json 取代電腦專案 public/content.json，再 Commit、Push，即可更新所有讀者看到的內容。

本版無後端，帳密只是入口遮擋，不能防止他人查看或繞過程式。任何人的本機編輯均不會自動修改你的 GitHub。不要使用與其他服務相同的密碼。草稿請定期匯出備份。
